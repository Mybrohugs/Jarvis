# JARVIS — дорожная карта после локального блока (27.10.2026)

Основа: проверенный локальный блок `developer_core/jarvis_local` (файлы и Office через V8,
браузер Playwright без сети, Windows: тестовое окно V2 с реальным кликом, подтверждённым
с клавиатуры, Блокнот с отдельной вкладкой JARVIS). Полный набор DEV: 337/337.

Источники ниже — результаты веб-поиска 27.10.2026. Цифры (звёзды, WER, бенчмарки) взяты
из карточек моделей, README и сторонних обзоров и **не проверялись нами**. Каждый пункт
сначала проходит отдельный DEV-этап: лицензия, хеши wheels, изолированный venv, тесты.

## Порядок работ (решение пользователя, 27.10.2026) — главнее этапов R0–R6 ниже
1. **Этап 1. Полностью рабочий JARVIS на Windows**: единый интерфейс, понимание
   русских команд, многошаговые планы с проверкой и отменой, автотесты. Приложения
   по приоритету:
   1. Проводник Windows (файлы и папки);
   2. браузер (навигация, поиск, сайты);
   3. Excel;
   4. Word/PDF;
   5. Telegram Desktop (после отдельных разрешений).

   Готово:
   - `intent.py` + `plan_runner.py`, команда `ask`;
   - русский набор 31/31 (`tests/data/jarvis_ru_commands.json`);
   - отмена последнего действия;
   - остановка при сбое со списком того, что можно откатить.
2. **Этап 2. iPhone**: сначала PWA через Tailscale (готово, `docs/PHONE_STATION_RU.md`),
   затем нативное приложение. Expo Go на физическом iPhone требует Apple Developer
   Program и TestFlight (документация Expo), поэтому нативное приложение откладывается
   до решения о подписке. Заготовка Expo SDK 58 лежит в `Documents\Codex\JARVIS-Mobile`.
3. **Этап 3. Интеллект и голос**: Claude как облачный планировщик, Ollama как локальный
   резерв (RTX 2060 6 ГБ → T-lite-it-2.1 8B Q4), Whisper/GigaAM, своя модель маршрутизации.
   Модели выдают тот же JSON-план, что и `intent.py`; `validate_plan` и роутер решают,
   что исполнять.

## Неизменные принципы
1. Голос, Telegram, MCP и LLM могут **предлагать** действия; запись и UI выполняются
   только после одобрения в локальной консоли (Trusted Local Session).
2. Недоверенный контент (веб, документы, OCR, экран) не может сам запустить запись.
3. Каждое действие проходит цепочку: план → одобрение → действие → проверка → аудит →
   откат, если он возможен.
4. Новые приложения добавляются в разрешённый список по одному, после пробы на чтение.

## Свои идеи
1. **Единый файл политики** `jarvis_policy.yaml`: разрешённые приложения, действия, лимиты,
   папки, хосты. Роутер читает только его; изменить политику можно лишь командой,
   одобренной с клавиатуры.
2. **Аварийная остановка**: глобальная клавиша (например, Ctrl+Alt+Pause) мгновенно
   отменяет текущее и будущие действия до перезапуска сессии.
3. **Пометка источника данных (облегчённый CaMeL)**: у каждого значения есть происхождение
   (`user`, `web`, `document`, `ocr`). План, в котором аргумент записи пришёл из
   недоверенного источника, показывает это в окне одобрения красным.
4. **«Что на экране?»**: сводка активного окна через UIA и OCR, только чтение, без
   сохранения, по явной команде.
5. **Обучение по демонстрации (идея UFO)**: пользователь один раз делает действие, JARVIS
   записывает события UIA в макрос с проверками и потом повторяет его через то же
   двойное подтверждение.
6. **Центр отмены**: просмотр журнала аудита (TUI или локальная страница) с кнопкой
   отката у каждого обратимого действия.
7. **Ежедневная самопроверка**: smoke, проверка возможностей и целостности журнала;
   итог в утренней сводке и в Telegram (только уведомление, без управления).
8. **Голос только для чтения**: голосом можно спросить, найти и прочитать; любые записи
   голос лишь ставит в очередь на одобрение в консоли.
9. **Русский тестовый набор команд**: 100 фраз («скопируй отчёт в папку архив», «добавь
   строку в таблицу…») с эталонным планом. Сравниваются модели и промпты, считаются
   точность и ложные действия.

## Этапы
### R0 — закрыть текущее (1 неделя)
- Реальная запись в Блокнот (`scripts/jarvis_local_notepad_trial.ps1`) — нужен пользователь.
- Everything (`es.exe`): поиск по диску только имён, затем `file-import` в workspace с
  одобрением и SHA-256.
- Файл политики и аварийная остановка.
- **Приёмка**: тесты, аварийная остановка прерывает действие в тестовом окне.

### R1 — голосовой цикл (2–3 недели)
- Silero VAD + слово активации «Джарвис» (openWakeWord, обучение на синтетике Piper).
- Сравнение GigaAM-v3 (ONNX, CPU) и faster-whisper на 50 своих русских записях: WER,
  задержка, RAM. Остаётся лучший.
- Перебивание: остановка TTS, когда пользователь начинает говорить.
- **Приёмка**: менее 1 ложного срабатывания в час фонового шума; голосовые команды на
  чтение работают; записи только ставятся в очередь.

### R2 — мозг-планировщик (3 недели)
- Локальная LLM с вызовом инструментов (T-lite-it-2.1 8B, Qwen3 8B; T-pro 32B, если
  хватит VRAM): фраза → JSON-план задачи роутера. LLM ничего не исполняет.
- Облегчённый CaMeL с пометками источника; русский тестовый набор из 100 команд.
- **Приёмка**: не меньше 90 % верных планов, 0 записей без одобрения, отказ при
  инъекции из документа или веб-страницы.

### R3 — рабочий стол (по одному приложению)
- Калькулятор → Проводник (только чтение) → Excel и Word через UIA (сохранение только
  в копию) → обучение по демонстрации.
- OmniParser только как подсказка для окон без UIA.
- **Приёмка** на каждое приложение: проба на чтение, проверка переднего плана,
  двойное подтверждение, проверка результата, тест «чужое окно → отказ».

### R4 — документы
- Docling для PDF с таблицами; операции Word «заменить текст» (в копии, с отчётом
  различий) и пересчёт формул Excel.

### R5 — память
- Сначала замер: где FTS5 + Qdrant не справляются. Только потом Graphiti или Mem0
  локально. «Память экрана» по образцу screenpipe — только по явному включению.

### R6 — интерактивный браузер
- browser-use или Playwright с разрешённым списком сайтов, отдельным профилем,
  одобрением каждой отправки формы и проверкой страницы до и после.

## Чего не делать
- Подключать Windows-MCP или любого «агента рабочего стола» к Telegram, MCP или мобильному
  шлюзу напрямую.
- Разрешать голосу или LLM одобрять записи.
- Клонировать чужие голоса.
- Записывать экран без явного включения и исключений для паролей и банков.
