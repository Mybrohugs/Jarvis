# JARVIS — фишки 1–12 (27.10.2026)

Все возможности работают через Unified Task Router: подтверждение (с клавиатуры или
по разрешённому списку), проверка результата, журнал. С iPhone и голосом без кода
выполняются только задачи из списка, который одобрил пользователь:
громкость, звук, сценарии, поиск и отправка файла, буфер обмена, снимок экрана.

## Защиты
- **Свободная речь (6).** Сначала разбирают правила, LLM подключается, только если они не поняли фразу.
  - LLM видит только фразу пользователя.
  - Опасные слова отсекаются до модели.
  - `validate_plan` пропускает только известные задачи.
  - Проверка происхождения: каждый путь, текст и сайт в плане должен дословно встречаться во фразе.
  - Замер модели без правил: тестовый набор плюс свободные фразы (`scripts/eval_llm_planner.py`).
- **Файлы на iPhone (7).**
  - Ссылки одноразовые и действуют 10 минут.
  - Скачивание только с ключом устройства.
  - Ключи, профили браузеров, хранилища паролей и секреты JARVIS не отправляются.
  - Размер не больше 50 МБ.
- **Push (3).** Содержимое уведомлений зашифровано (RFC 8291). Закрытый VAPID-ключ остаётся на компьютере.
- **Голос (8).** Звук нигде не сохраняется, в журнал попадают названия задач и длина фразы.
- **Календарь в брифинге** выключен: токены Google лежат в корне Telegram-бота, а JARVIS эту папку не трогает.
