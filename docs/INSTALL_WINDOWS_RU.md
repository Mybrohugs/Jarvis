# JARVIS v1.4.3 — установщик Windows

Один файл: **JARVIS-Setup-v1.4.3-windows-x64.exe**. Включает текстовый ChatGPT, отправку интернет-видео на ТВ, Python, Chromium и FFmpeg. Старый голосовой интерфейс остаётся отдельным приложением.

1. Запустите установщик и завершите установку.
2. Откройте **Пуск → JARVIS DEV Station**.
3. При первом запуске на другом ПК нажмите «Войти в ChatGPT», затем настройте телевизор на вкладке видео. Ключ Claude не нужен.

Установка выполняется для текущего пользователя в отдельную папку JARVIS-DEV-Station. При обновлении настройки, вход ChatGPT и привязка YouTube сохраняются. На этом ПК существующие DEV-настройки уже перенесены. Установщик не включает автозапуск, не меняет production или маршруты Tailscale. Если окно станции открыто, сначала закройте его.

Удаление: **Параметры Windows → Приложения → Установленные приложения → JARVIS DEV Station → Удалить**. Настройки и общий защищённый профиль ChatGPT сохраняются; прежние версии, установленные отдельно, остаются как резервные копии.

Версию можно откатить через Rollback-DEV.cmd в папке установленной версии, если предыдущая версия доступна. После отката ярлык в «Пуск» запускает выбранную версию.

Установщик содержит обе локализации: русский и английский. Цифровая подпись издателя JARVIS в этой сборке отсутствует. Компилятор Inno Setup загружен с официального сайта проекта и проверен по SHA256 и подписи Pyrsys B.V.; компиляция выполняется только внутри Windows Sandbox.
