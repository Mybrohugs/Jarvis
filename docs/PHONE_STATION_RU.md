# JARVIS на iPhone: приложение и мини-станция

`developer_core/jarvis_local/pwa_gateway.py` — устанавливаемое веб-приложение (PWA) для
iPhone в стиле HUD и «мини-станция» с голосом через Siri.

**Граница безопасности.** Телефон — удалённый канал. Он читает сводку, журнал без
подробностей и очередь, а также добавляет текстовые запросы в очередь. Выполнить что-либо
с телефона нельзя: шлюз не импортирует роутер, сессию и исполнители, это проверяет тест.
Запросы из очереди вы выполняете за компьютером обычными командами с подтверждением.

## 1. Запуск на компьютере
Из `coding-agent`, в PowerShell:
```powershell
$env:JARVIS_PWA_TOKEN = .venv-integrations/Scripts/python.exe -c "import secrets; print(secrets.token_hex(32))"
$env:JARVIS_PWA_TOKEN   # ключ для телефона; не пересылайте его в чатах
.venv-integrations/Scripts/python.exe -m developer_core.jarvis_local.pwa_gateway `
  --workspace "$env:USERPROFILE\Documents\Codex\UFO-Research\FunctionalWorkspace" --port 10790 `
  --allow-host ВАШ-ПК.ВАША-СЕТЬ.ts.net
```
Шлюз слушает только `127.0.0.1`. Новый запуск с новым ключом отзывает старый ключ.

## 2. Связь с iPhone через Tailscale (ставите сами)
1. Установите Tailscale на компьютер и iPhone, войдите в одну сеть.
2. В админ-панели Tailscale включите MagicDNS и HTTPS Certificates.
3. На компьютере: `tailscale serve --bg 10790`. Адрес будет `https://ВАШ-ПК.ВАША-СЕТЬ.ts.net`.
   Это имя передаётся в `--allow-host`.
4. Наружу в интернет ничего не открывается; доступ есть только у устройств вашей сети.

*Не проверено на реальном iPhone:* передача заголовка `Host` через `tailscale serve`
и работа PWA на iOS 26. Если увидите ошибку `421`, сообщите мне.

## 3. Установка приложения
Safari → адрес из шага 2 → «Поделиться» → «На экран Домой». Откройте JARVIS с иконки,
введите ключ и при желании включите «Запомнить на этом iPhone». Ключ хранится
в `localStorage` этого приложения; «Забыть ключ» удаляет его.

Вкладки:
- **Станция** — ядро-реактор, запрос текстом или голосом (микрофон на клавиатуре iPhone),
  ответы вслух, режим «экран не гаснет» для станции на подставке;
- **Сводка** — шкалы: действия за сутки, требующие внимания, запросы в очереди;
- **Очередь** и **Журнал** — телеметрия.

## 4. Мини-станция «Привет, Siri, Джарвис»
Быстрые команды → «+» → назовите «Джарвис» и добавьте действия:
1. **Диктовать текст** (язык: русский).
2. **Получить содержимое URL**: `https://ВАШ-ПК.ВАША-СЕТЬ.ts.net/api/say`, метод **POST**,
   заголовок `Authorization` = `Bearer <ключ>`, тело запроса **JSON**: поле `text` =
   «Продиктованный текст».
3. **Получить значение словаря** по ключу `speech`.
4. **Произнести текст**.

Скажите «Привет, Siri, Джарвис» и затем фразу. Работает и с заблокированного экрана.
Ключ хранится внутри Быстрой команды; не делитесь этой командой.

Что понимает станция сейчас (без LLM, фиксированные фразы):
- «статус», «сводка», «как дела» — сводка за сутки;
- «что в очереди», «мои запросы» — состояние очереди;
- всё остальное записывается в очередь с ответом «Записал. Выполню после подтверждения за компьютером».

## 5. Очередь на компьютере
```powershell
$py='.\.venv-integrations\Scripts\python.exe'; $ws="$env:USERPROFILE\Documents\Codex\UFO-Research\FunctionalWorkspace"
& $py -B -m developer_core.jarvis_local.cli --workspace $ws phone-queue
& $py -B -m developer_core.jarvis_local.cli --workspace $ws phone-queue-close <id> done
```

## Проверки
`tests/test_jarvis_pwa.py`, реальный loopback HTTP:
- раздача файлов, CSP и заголовки безопасности;
- ключ и защита по Host;
- голосовые ответы и очередь;
- лимиты ввода;
- журнал без подробностей;
- статическая проверка, что шлюз не импортирует исполнители.

Внешний вид проверен рендером в Playwright с размером экрана iPhone 17 Pro.
Реальный iPhone, Tailscale и Siri не проверялись.
