      «Поделиться → Джарвис» на iPhone
      1. Команды → «+» → «Получить содержимое URL».
      2. URL:
      3. Метод POST, тело запроса «Файл» → «Ввод быстрой команды».
      4. Заголовок Authorization:
      5. В настройках команды включить «Показывать в меню “Поделиться”», назвать «Джарвис».

      Ключ даёт доступ к JARVIS: храните его только в этой команде.

      «Поделиться → На ТВ» (видео YouTube)
      1. Один раз: в YouTube на телевизоре «Настройки → Подключить по коду», скажите JARVIS «привяжи телевизор, код …».
      2. Команды → «+» → «Текст»: на телевизор и «Ввод быстрой команды» сразу после пробела.
      3. «Получить содержимое URL»: , метод POST, тело JSON: поле text = «Текст».
      4. Заголовок Authorization: тот же ключ (кнопка выше).
      5. Включить «Показывать в меню “Поделиться”», назвать «На ТВ».
